# src/lib

## Overview
Shared cross-cutting infrastructure and utility modules used across the Next.js server/client application and BFF layer:
- **Authentication & Authorization**: Better Auth server instance with Drizzle SQLite adapter and Resend transactional emails (`auth.ts`), lazy-initialized Better Auth React client proxy (`auth-client.ts`), and server-side role guard (`require-role.ts`).
- **GitHub Integration**: GitHub App Octokit client for challenge repository provisioning, candidate forking, archiving, recursive text tree extraction, and commit counting (`github.ts`).
- **Document & Content Processing**: Uploaded job-post file validation and text extraction for PDF/DOCX/TXT/MD (`file-extractor.ts`), sanitized Markdown rendering (`safe-markdown.ts`), and recruiter challenge brief rendering with heading slugs and table of contents (`recruiter-challenge-brief.ts`).
- **Utilities**: ANSI console logging helpers (`log-helpers.ts`), JSON tech-stack string formatting (`parse-tech-stack.ts`), and Tailwind class merging (`utils.ts`).

Note: `job-post-processor.README.md` is an existing standalone implementation guide in this directory documenting file extraction (matching `file-extractor.ts`) alongside broader Mastra/DB/Server Action pipeline notes (including early-stage placeholder snippets).

## Interface
- `authClient` — `Proxy` lazily initializing Better Auth React client on first property access `[auth-client.ts:authClient]`
- `resend` — Resend SDK client initialized with `process.env.RESEND_API_KEY` `[auth.ts:resend]`
- `auth` — Better Auth server instance configured with Drizzle SQLite, email/password verification, and Resend email hooks `[auth.ts:auth]`
- `FILE_UPLOAD_CONFIG`, `type AllowedFileExtension`, `class FileValidationError`, `validateFile(file: File): void`, `extractTextFromFile(file: File): Promise<string>`, `getFileMetadata(file: File)` — file upload validation and PDF/DOCX/TXT/MD text extraction `[file-extractor.ts:FILE_UPLOAD_CONFIG]`, `[file-extractor.ts:AllowedFileExtension]`, `[file-extractor.ts:FileValidationError]`, `[file-extractor.ts:validateFile]`, `[file-extractor.ts:extractTextFromFile]`, `[file-extractor.ts:getFileMetadata]`
- `getGitHubClient()`, `createChallengeRepo(challengeId, readmeContent, starterFiles)`, `forkChallengeRepo(repoName, candidateAlias)`, `archiveFork(forkName)`, `getRepoTree(repoName)`, `getCommitCount(repoName)`, `github` — GitHub App repository lifecycle operations `[github.ts:getGitHubClient]`, `[github.ts:createChallengeRepo]`, `[github.ts:forkChallengeRepo]`, `[github.ts:archiveFork]`, `[github.ts:getRepoTree]`, `[github.ts:getCommitCount]`, `[github.ts:github]`
- `message(message: string)`, `log(message: string, data: unknown)`, `logError(message: string, data: unknown)` — ANSI-colored stdout logging helpers `[log-helpers.ts:message]`, `[log-helpers.ts:log]`, `[log-helpers.ts:logError]`
- `parseTechStack(raw: string): string` — parses a JSON string array into a comma-separated string, falling back to `raw` `[parse-tech-stack.ts:parseTechStack]`
- `type ChallengeBriefTocItem`, `renderRecruiterChallengeBrief(raw: string): Promise<{ html: string; toc: ChallengeBriefTocItem[] }>` — renders sanitized Markdown HTML and heading TOC (`depth <= 3`) `[recruiter-challenge-brief.ts:ChallengeBriefTocItem]`, `[recruiter-challenge-brief.ts:renderRecruiterChallengeBrief]`
- `type SessionUserPlain`, `requireRole(role: 'candidate' | 'recruiter'): Promise<SessionUserPlain>` — server-side session and role guard `[require-role.ts:SessionUserPlain]`, `[require-role.ts:requireRole]`

- `cn(...inputs: ClassValue[]): string` — merges class names with `clsx` and `tailwind-merge` `[utils.ts:cn]`

## Invariants
- **Auth client lazy init & baseURL**: Initializes once on first property access with `lastLoginMethodClient()` and `organizationClient()`; uses `window.location.origin` in the browser and `process.env.NEXT_PUBLIC_API_URL ?? ''` (passed as `undefined` if empty) on the server `[auth-client.ts:getBaseURL]`, `[auth-client.ts:getAuthClient]`, `[auth-client.ts:authClient]`.
- **Auth server schema & verification**: Uses Drizzle SQLite adapter (`provider: 'sqlite'`), `nextCookies()`, `emailAndPassword.enabled = true`, `requireEmailVerification = true`, `sendOnSignUp = true`, and required `user.additionalFields` (`role` default `'candidate'`, `dateOfBirth`, `termsAcceptedAt`, `privacyPolicyAcceptedAt`). Emails send from `'basil@after42.ai'` with `'fr'` vs English subject selected via `localeFromAuthUrl(url)` `[auth.ts:auth]`.
- **Role guard enforcement**: `requireRole` allows only `'candidate' | 'recruiter'`; it calls `authController.requireSession(await headers())` (which redirects unauthenticated callers to localized `'/'`) and redirects to localized `/dashboard` whenever the destructured `user` is falsy (`!userPlain`) or `userPlain.role !== role` `[require-role.ts:requireRole]`.
- **File upload validation & text sanitization**: Enforces `MAX_FILE_SIZE = 10 * 1024 * 1024` bytes (`FILE_TOO_LARGE`) and whitelists both MIME type (`ALLOWED_MIME_TYPES`) and lowercase extension (`.pdf`, `.docx`, `.txt`, `.md`, throwing `INVALID_FILE_TYPE`/`INVALID_EXTENSION`); `extractTextFromFile` always validates before reading bytes, wraps parser errors as `EXTRACTION_FAILED`, and strips `\0`, normalizes line endings to `\n`, replaces `\t` with spaces, collapses spaces, and trims `[file-extractor.ts:FILE_UPLOAD_CONFIG]`, `[file-extractor.ts:validateFile]`, `[file-extractor.ts:extractTextFromFile]`, `[file-extractor.ts:sanitizeText]`.
- **GitHub credentials, singleton caching & repo rules**: Requires `GITHUB_APP_ID`, base64-encoded PEM `GITHUB_APP_PRIVATE_KEY`, and `GITHUB_ORG_NAME` (throwing `Error` if absent), caching `cachedInstallationId` and `installationOctokit` at module scope `[github.ts:ORG]`, `[github.ts:requireGithubEnv]`, `[github.ts:getInstallationId]`, `[github.ts:getGitHubClient]`. `createChallengeRepo` creates private `challenge-${challengeId}` on `refs/heads/main`, stripping leading `/` and skipping empty or `'..'` paths `[github.ts:createChallengeRepo]`. `forkChallengeRepo` sanitizes fork names to `[a-zA-Z0-9._-]`, polls `repos.get` up to 30 times every `2000ms`, swallows `addCollaborator` errors after logging, and falls back `cloneUrl` to `https://github.com/${org}/${ready.name}.git` `[github.ts:forkChallengeRepo]`. `getRepoTree` skips non-`blob` entries and null-byte binary files `[github.ts:getRepoTree]`, `[github.ts:isProbablyText]`; `getCommitCount` paginates `per_page: 100` until a page returns `< 100` items `[github.ts:getCommitCount]`.
- **Markdown sanitization & TOC rules**: Both `renderMarkdown` and `renderRecruiterChallengeBrief` sanitize rendered HTML with `DOMPurify.sanitize(html)` `[safe-markdown.ts:renderMarkdown]`, `[recruiter-challenge-brief.ts:renderRecruiterChallengeBrief]`. `renderRecruiterChallengeBrief` instantiates a fresh `new Marked()` per call, emits TOC entries/IDs only for non-empty headings with `depth <= 3`, slugifies to max 80 chars (fallback `'section'`), and deduplicates slugs with `-2`, `-3`, etc. `[recruiter-challenge-brief.ts:slugify]`, `[recruiter-challenge-brief.ts:renderRecruiterChallengeBrief]`.
- **Tech stack fallback**: `parseTechStack` joins items with `', '` only if `JSON.parse(raw)` returns an array; otherwise returns `raw` unchanged `[parse-tech-stack.ts:parseTechStack]`.

## Side Effects
- **Environment & browser API reads**: Reads `process.env.NEXT_PUBLIC_API_URL` and `window.location.origin` `[auth-client.ts:getBaseURL]`, `process.env.RESEND_API_KEY` `[auth.ts:resend]`, and `process.env.GITHUB_ORG_NAME`, `GITHUB_APP_ID`, `GITHUB_APP_PRIVATE_KEY` `[github.ts:ORG]`, `[github.ts:requireGithubEnv]`.
- **Database, cookies & Next.js request/navigation**: Binds Better Auth to `@/db` SQLite and mutates response cookies via `nextCookies()` `[auth.ts:auth]`; reads request headers (`headers()`), resolves locale (`getLocale()`), verifies sessions via `authController.requireSession(...)`, and triggers `redirect({ href: '/dashboard', locale: await getLocale() })` `[require-role.ts:requireRole]`.
- **Outbound network calls**: Dispatches transactional emails via `resend.emails.send` `[auth.ts:auth]`; invokes GitHub REST APIs via Octokit (`apps.getOrgInstallation`, `repos.createInOrg`, `repos.createFork`, `repos.get`, `repos.addCollaborator`, `repos.update`, `repos.listCommits`, and `git.createBlob`/`createTree`/`createCommit`/`createRef`/`getRef`/`getCommit`/`getTree`/`getBlob`) `[github.ts:getInstallationId]`, `[github.ts:createChallengeRepo]`, `[github.ts:forkChallengeRepo]`, `[github.ts:archiveFork]`, `[github.ts:getRepoTree]`, `[github.ts:getCommitCount]`.
- **Timers & module-level cache mutations**: Polls with `setTimeout` (`2000ms`, up to 30 times) `[github.ts:sleep]`, `[github.ts:forkChallengeRepo]`; mutates module singletons `_authClient` `[auth-client.ts:getAuthClient]`, `cachedInstallationId`, and `installationOctokit` `[github.ts:getInstallationId]`, `[github.ts:getGitHubClient]`.
- **Buffer parsing & stdout logging**: Reads `file.arrayBuffer()` and parses via `PDFParse`, `mammoth.extractRawText`, or `TextDecoder('utf-8')` `[file-extractor.ts:extractTextFromFile]`, `[file-extractor.ts:extractFromPDF]`, `[file-extractor.ts:extractFromDocx]`, `[file-extractor.ts:extractFromText]`; writes ANSI-formatted logs to `console.log` `[log-helpers.ts:message]`, `[log-helpers.ts:log]`, `[log-helpers.ts:logError]`, `[github.ts:forkChallengeRepo]`.
