# Candidate Components (`src/components/candidate`)

## Overview
Provides the three client-side UI components that manage a candidate's challenge execution lifecycle after reading a challenge brief: `ForkChallengeBtn` provisions a personal GitHub fork via server action and navigates to the submission workspace; `SubmitWorkspace` displays Git clone/push instructions, polls commit counts against the fork, tracks readiness, and submits/archives the repository; and `TerminalState` renders read-only post-submission views once a submission enters a locked, scored, or failed state.

## Interface
- `ForkChallengeBtn({ challengeId }: { challengeId: string })` (`'use client'`, named export): Renders the action button that triggers `forkChallenge(challengeId)` and navigates to the submission route `[fork-challenge-btn.tsx:ForkChallengeBtn]`, `[fork-challenge-btn.tsx:Props]`.
- `SubmitWorkspace({ challengeId, cloneUrl, submission, challenge })` (`'use client'`, named export): Renders the submission workspace with clone/push copyable commands, live commit polling banner, readiness checklist, README preview, and archive/submit action. Accepts `challengeId: string`, `cloneUrl: string`, `submission: { id: string; githubForkName: string; sequenceNum: number }`, and `challenge: { title: string; challengeContent: { readme: string } | null }` `[submit-workspace.tsx:SubmitWorkspace]`, `[submit-workspace.tsx:Props]`.
- `TerminalState({ submission })` (`'use client'`, named export): Renders read-only terminal submission cards or `null` for non-terminal states. Accepts `submission: { status: string; score: number | null; submittedAt: Date | null; sequenceNum: number }` `[terminal-state.tsx:TerminalState]`, `[terminal-state.tsx:SubmissionLite]`.

## Invariants
- `ForkChallengeBtn` disables its button while `isPending` is true (`disabled={isPending}`); `handleClick` checks `'error' in result` and sets `error` state without navigating `[fork-challenge-btn.tsx:ForkChallengeBtn]`, `[fork-challenge-btn.tsx:handleClick]`. Button labels transition across `isPending` (`"Setting up repository…"`), truthy `error` (`"Retry"`), and default (`"Complete Challenge"`), and truthy `error` renders a fixed fallback error message rather than displaying `result.error` verbatim `[fork-challenge-btn.tsx:ForkChallengeBtn]`.
- `SubmitWorkspace` URL-encodes `submission.githubForkName` with `encodeURIComponent` during polling, ignores non-OK HTTP responses and thrown errors, and updates `commitCount` only when `typeof data.commits === 'number'` `[submit-workspace.tsx:poll]`.
- The `"Archive Repo & Submit"` button is disabled whenever `isPending || commitCount === null || commitCount === 0`, displays tooltip `"Push your code first"` when `commitCount === 0 || commitCount === null`, and references the `aria-live="polite"` / `aria-atomic="true"` status banner via `aria-describedby` `[submit-workspace.tsx:SubmitWorkspace]`.
- Status banner copy and border color branch strictly on `commitCount`: `null` (`"Checking repository…"` / `#C2410C`), `0` (`"● Waiting for your first push…"` / `#C2410C`), `1` (`"● First commit received! Keep going."` / `#D97706`), and `>= 2` (`"● {commitCount} commits pushed. Ready to submit."` / `#16A34A`). Checklist marks `"Repository created"` unconditionally checked and marks `"Code pushed"` and `"Ready to submit"` checked iff `commitCount != null && commitCount >= 1` `[submit-workspace.tsx:SubmitWorkspace]`.
- After `submitChallenge(submission.id)` resolves, `router.refresh()` runs only when `'ok' in res && res.ok`; non-ok responses are not surfaced in UI `[submit-workspace.tsx:SubmitWorkspace]`.
- `stripMarkdownLite` strips fenced code blocks, inline code backticks, ATX headings, bold/italic markers, and markdown link targets, collapses whitespace, and truncates to `400` characters; the preview block renders only when the stripped preview is non-empty `[submit-workspace.tsx:stripMarkdownLite]`, `[submit-workspace.tsx:SubmitWorkspace]`.
- Git command templates interpolate `git clone ${cloneUrl}` and hardcode pushing to `origin main` (`git add .\ngit commit -m "my changes"\ngit push origin main`) `[submit-workspace.tsx:SubmitWorkspace]`.
- `TerminalState` handles only explicit statuses: `'submitted'` or `'scoring'` renders the locked/scoring view; `'scored'` with `submission.score != null` renders `{score}/100` colored `#16A34A` (`>= 80`), `#D97706` (`>= 60`), or `#DC2626` (`< 60`); `'failed'` renders `"Scoring failed."`; all other statuses (or `'scored'` with `score == null`) return `null`. Missing `submittedAt` falls back to `'recently'` `[terminal-state.tsx:TerminalState]`.
- `submission.sequenceNum` is required in both `SubmitWorkspace` and `TerminalState` prop types even though neither component reads it `[submit-workspace.tsx:Props]`, `[terminal-state.tsx:SubmissionLite]`.

## Side Effects
- `ForkChallengeBtn` invokes server action `forkChallenge(challengeId)` (`@/app/actions/fork-challenge`) inside `startTransition` and navigates via i18n `router.push(\`/candidate/challenges/${challengeId}/submit\`)` on success `[fork-challenge-btn.tsx:handleClick]`.
- `SubmitWorkspace` polls `GET /api/commits/${encodeURIComponent(submission.githubForkName)}` with `{ credentials: 'same-origin' }` via an immediate `window.setTimeout(..., 0)` and a `10_000` ms `window.setInterval` cleaned up on unmount `[submit-workspace.tsx:poll]`, `[submit-workspace.tsx:useEffect]`.
- `SubmitWorkspace` writes command snippets to the system clipboard via `navigator.clipboard.writeText(text)` (silently swallowing errors) and schedules a `2000` ms `setTimeout` to reset copied state `[submit-workspace.tsx:copyToClipboard]`.
- `SubmitWorkspace` invokes server action `submitChallenge(submission.id)` (`@/app/actions/submit-challenge`) inside `startTransition`, triggers i18n `router.refresh()` on `'ok' in res && res.ok`, and renders a declarative i18n `<Link href={\`/candidate/challenges/${challengeId}\`}>` `[submit-workspace.tsx:SubmitWorkspace]`.
- `TerminalState` has no external side effects (pure presentational render formatting `submittedAt` with `formatDistanceToNow`) `[terminal-state.tsx:TerminalState]`.
