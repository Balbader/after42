# Auth Components (`src/components/auth`)

## Overview
Provides client-facing authentication UI components, forms, and layout/field primitives covering sign-in, two-step role-based sign-up, sign-out, and password recovery/reset flows. Sign-in and sign-up (`SignInForm`, `SignUpForm`, `SignUpDateField`, `SignUpTermsField`, `SignUpFlow`, `AuthPanel`) use `@tanstack/react-form-nextjs` with Zod validation, while password recovery (`ForgotPasswordForm`, `ResetPasswordForm`) uses `react-hook-form` with Zod validation. Authentication operations call either Better Auth client methods (`authClient.signIn.email`, `authClient.requestPasswordReset`, `authClient.resetPassword`) or Next.js server actions (`signUpAction`, `signOutAction` from `@/app/actions/auth`), paired with `next-intl` translations/routing and `sonner` toast feedback.

## Interface
- `AuthBrandAside({ tagline }: { tagline: string })` (named export, no `'use client'`): Renders the split-screen brand panel with a `<Link href='/'>` mark and tagline `[auth-brand-aside.tsx:AuthBrandAside]`.
- `AuthPanel()` (`'use client'`, named export): Renders tabbed `signin` / `signup` authentication views composing `SignInForm` and `SignUpForm` `[auth-panel.tsx:AuthPanel]`.
- `ForgotPasswordForm({ className, ...props }: React.ComponentProps<'div'>)` (`'use client'`, named export): Email form requesting a localized password-reset link `[forgot-password-form.tsx:ForgotPasswordForm]`.
- `ResetPasswordForm({ className, ...props }: React.ComponentProps<'div'>)` (`'use client'`, named export): `<Suspense>`-wrapped password reset form reading `token` from query params and submitting a new password `[reset-password-form.tsx:ResetPasswordForm]`.
- `SignInFormProps` (`export type SignInFormProps = { className?: string }`) and `SignInForm({ className }: SignInFormProps)` (`'use client'`, named export): Email/password sign-in form `[sign-in-form.tsx:SignInFormProps]`, `[sign-in-form.tsx:SignInForm]`.
- `SignOutButton()` (`'use client'`, named export): Button invoking `signOutAction()` and redirecting to `'/'` `[sign-out-btn.tsx:SignOutButton]`.
- `SignUpDateField({ value, isTouched, isValid, errors, onChange })` (named export, no `'use client'`; expects client parent): Date-of-birth calendar popover field accepting millisecond timestamp `value: number` and `onChange: (val: number) => void` `[sign-up-date-field.tsx:SignUpDateField]`.
- `SignUpFlow({ titleClassName }: { titleClassName?: string })` (`'use client'`, named export): Two-step onboarding container selecting `'recruiter' | 'candidate'` before rendering `<SignUpForm initialRole={selectedRole} hideRoleSelect />` `[sign-up-flow.tsx:SignUpFlow]`.
- `SignUpForm({ initialRole = 'candidate', hideRoleSelect = false })` (`'use client'`, named export): Account registration form for `'candidate' | 'recruiter'` roles `[sign-up-form.tsx:SignUpForm]`.
- `SignUpTermsField({ name, value, isTouched, isValid, errors, onChange, onBlur })` (named export, no `'use client'`; expects client parent): Terms-of-service and privacy-policy consent checkbox field `[sign-up-terms-field.tsx:SignUpTermsField]`.

## Invariants
- `AuthBrandAside` hides below the `md` breakpoint (`hidden ... md:flex`) `[auth-brand-aside.tsx:AuthBrandAside]`; `AuthPanel` initializes on tab `'signin'` with fixed keys `'signin'` and `'signup'` `[auth-panel.tsx:AuthPanel]`.
- `ForgotPasswordForm` validates `email` via `z.string().email(...)` with `formSchema.safeParse(values)` (aborting with `form.setError('email', ...)` on failure), always computes `redirectTo: \`/${locale}/reset-password\`` from `useLocale()`, disables submission while `isLoading === true` (reset in `finally`), and throws on truthy `{ error }` from `authClient.requestPasswordReset` `[forgot-password-form.tsx:ForgotPasswordForm]`, `[forgot-password-form.tsx:onSubmit]`.
- `ResetPasswordForm` wraps `ResetPasswordFormInner` (`useSearchParams()`) in `<Suspense>` `[reset-password-form.tsx:ResetPasswordForm]`. `onSubmit` enforces three sequential pre-call gates: (1) Zod `min(8)` validation on `password` and `confirmPassword`, (2) non-empty `searchParams.get('token')?.trim()`, and (3) `password === confirmPassword`. Disables submit while `isLoading === true` (reset in `finally`) and navigates to `'/'` only if `authClient.resetPassword` succeeds without `error` `[reset-password-form.tsx:ResetPasswordFormInner]`, `[reset-password-form.tsx:onSubmit]`.
- `SignInForm` validates `email` (`z.string().email`) and `password` (`z.string().min(8)`) on submit, renders invalid field UI only when `isTouched && !isValid`, disables submit (`form='signin-form'`) while `form.state.isSubmitting`, passes localized `callbackURL: \`/${locale}/dashboard\``, extracts error text via `authClientErrorMessage` only when `error.message` is a non-empty string, and navigates to `'/dashboard'` only after `toast.promise(...).unwrap()` succeeds `[sign-in-form.tsx:SignInForm]`, `[sign-in-form.tsx:authClientErrorMessage]`.
- `SignOutButton` checks `result.success` from `signOutAction()` and throws `new Error(t('toastError'))` when falsy so `router.push('/')` and `router.refresh()` do not run `[sign-out-btn.tsx:handleSignOut]`.
- `SignUpFlow` begins at `step === 'role'` with `selectedRole === null`, disables Continue until a role (`'recruiter' | 'candidate'`) is chosen, and transitions one-way into `<SignUpForm initialRole={selectedRole} hideRoleSelect />` `[sign-up-flow.tsx:SignUpFlow]`.
- `SignUpForm` defaults `initialRole = 'candidate'` and `hideRoleSelect = false`; hiding the role select omits the `<Select>` UI while retaining `defaultValues.role = initialRole` in submission payload. Its Zod schema requires `role` in `['candidate', 'recruiter']`, non-empty `first_name` and `last_name`, valid `email`, `password` length `>= 8`, `dateOfBirth >= 1`, and `termsAccepted === true`. Stamps `termsAcceptedAt` and `privacyPolicyAcceptedAt` with the same `Date.now().toString()`, disables submit while `isSubmitting`, and throws when `!result.success` `[sign-up-form.tsx:SignUpForm]`.
- `SignUpDateField` encodes unset dates as `0`, restricts calendar selection to `1900-01-01` through `new Date()`, and gates invalid state on `isTouched && !isValid` `[sign-up-date-field.tsx:SignUpDateField]`.
- `SignUpTermsField` strictly normalizes Radix checked state via `value === true` and `onChange(checked === true)` (coercing `'indeterminate'` to `false`) and wires `aria-describedby={`${name}-error`}` when `isTouched && !isValid` `[sign-up-terms-field.tsx:SignUpTermsField]`.

## Side Effects
- `ForgotPasswordForm` calls `authClient.requestPasswordReset({ email, redirectTo: \`/${locale}/reset-password\` })`, triggers `toast.promise(...).unwrap()`, mutates loading/form error state, and links to `/sign-up`, `/terms`, and `/privacy` `[forgot-password-form.tsx:onSubmit]`, `[forgot-password-form.tsx:ForgotPasswordForm]`.
- `ResetPasswordForm` reads `token` from `useSearchParams()`, calls `authClient.resetPassword({ newPassword, token })`, emits `toast.error` / `toast.promise`, navigates via `router.push('/')` on success, and links to `/sign-up`, `/terms`, and `/privacy` `[reset-password-form.tsx:ResetPasswordFormInner]`, `[reset-password-form.tsx:onSubmit]`.
- `SignInForm` calls `authClient.signIn.email({ email, password, callbackURL: \`/${locale}/dashboard\` })`, emits `toast.error` / `toast.promise`, navigates via `router.push('/dashboard')` on success, and links to `/forgot-password` and `/sign-up` `[sign-in-form.tsx:SignInForm]`.
- `SignOutButton` calls server action `signOutAction()` (`@/app/actions/auth`), displays `toast.promise`, and runs `router.push('/')` followed by `router.refresh()` on success `[sign-out-btn.tsx:handleSignOut]`.
- `SignUpForm` calls server action `signUpAction(formData)` (`@/app/actions/auth`), emits `toast.error` / `toast.promise`, logs submission values and errors via `log(...)` (`@/lib/log-helpers`), resets form state on Clear (`form.reset()`), and links to `/sign-in` (no automatic redirect on sign-up) `[sign-up-form.tsx:SignUpForm]`.
- `SignUpFlow` mutates local role/step state (`setSelectedRole`, `setStep`) `[sign-up-flow.tsx:SignUpFlow]`; `SignUpDateField` and `SignUpTermsField` invoke caller-provided `onChange`/`onBlur` callbacks and `SignUpTermsField` links to `/terms` and `/privacy` `[sign-up-date-field.tsx:SignUpDateField]`, `[sign-up-terms-field.tsx:SignUpTermsField]`; `AuthBrandAside` renders `<Link href='/'>` `[auth-brand-aside.tsx:AuthBrandAside]`.
