# AI Elements (`src/components/ai-elements`)

## Overview
Domain-specific AI interaction component library consisting of 48 standalone TSX modules with no barrel index or child subdirectories. Built atop `src/components/ui` primitives and specialized libraries (`ai` Vercel AI SDK types, `streamdown` + `@streamdown/{cjk,code,math,mermaid}`, `shiki`, `@xyflow/react`, `use-stick-to-bottom`, `tokenlens`, `media-chrome/react`, `@rive-app/react-webgl2`, `motion/react`, `react-jsx-parser`, `ansi-to-react`, `@radix-ui/react-use-controllable-state`, `nanoid`), these compound components render chat conversations, multi-branch markdown responses, prompt composers with attachments/sources, tool invocations and approval gates, reasoning traces, code/diff/terminal/test/schema/JSX/web previews, audio/speech/transcription/voice/mic controls, animated Rive personas, and React Flow workflow graphs. Most modules declare `"use client"`; 8 modules omit it (`canvas.tsx`, `connection.tsx`, `edge.tsx`, `image.tsx`, `model-selector.tsx`, `node.tsx`, `panel.tsx`, `toolbar.tsx`).

  - `useConfirmation` throws outside `<Confirmation>` `[confirmation.tsx:useConfirmation]`.
  - `useContextValue` throws outside `<Context>` `[context.tsx:useContextValue]`.
  - `useJSXPreview` throws outside `<JSXPreview>` `[jsx-preview.tsx:useJSXPreview]`.
  - `useMessageBranch` throws outside `<MessageBranch>` `[message.tsx:useMessageBranch]`.
  - `useOpenInContext` throws outside `<OpenIn>` `[open-in-chat.tsx:useOpenInContext]`.
  - `usePlan` throws outside `<Plan>` `[plan.tsx:usePlan]`.
  - `usePromptInputController` and `useProviderAttachments` throw outside `<PromptInputProvider>`; `usePromptInputAttachments` prefers `LocalAttachmentsContext` over `ProviderAttachmentsContext` and throws outside both; `usePromptInputReferencedSources` throws outside `<PromptInput>` `[prompt-input.tsx:usePromptInputController]` `[prompt-input.tsx:usePromptInputAttachments]` `[prompt-input.tsx:usePromptInputReferencedSources]`.
  - `useReasoning` throws outside `<Reasoning>` `[reasoning.tsx:useReasoning]`.

  - `useTranscription` throws outside `<Transcription>` `[transcription.tsx:useTranscription]`.
  - `useVoiceSelector` throws outside `<VoiceSelector>` `[voice-selector.tsx:useVoiceSelector]`.
  - `useWebPreview` throws outside `<WebPreview>` `[web-preview.tsx:useWebPreview]`.
  - Non-throwing fallback contexts exist in `CodeBlockContext`, `EnvironmentVariablesContext`/`EnvironmentVariableContext`, `FileTreeContext`/`FileTreeFolderContext`/`FileTreeFileContext`, `useCarouselApi`, `MicSelectorContext`, `PackageInfoContext`, `SchemaDisplayContext`, `SnippetContext`, `TerminalContext`, `TestResultsContext`/`TestSuiteContext`/`TestContext` `[code-block.tsx:CodeBlockContext]` `[environment-variables.tsx:EnvironmentVariables]` `[environment-variables.tsx:EnvironmentVariableContext]` `[file-tree.tsx:FileTree]` `[file-tree.tsx:FileTreeFolderContext]` `[inline-citation.tsx:useCarouselApi]` `[mic-selector.tsx:MicSelectorContext]` `[package-info.tsx:PackageInfoContext]` `[schema-display.tsx:SchemaDisplayContext]` `[snippet.tsx:Snippet]` `[terminal.tsx:TerminalContext]` `[test-results.tsx:TestResults]`.
- **External framework & parent-container requirements**:
  - React Flow modules (`Controls`, `Edge.Animated`, `Node`, `Panel`, `Toolbar`) require a React Flow canvas/provider context (and `Toolbar` requires a node context); `Edge.Animated` returns `null` when internal source/target nodes are missing, hardcodes `Position.Right -> Position.Left`, and throws on unrecognized `Position` values `[controls.tsx:Controls]` `[edge.tsx:Animated]` `[edge.tsx:getHandleCoordsByPosition]` `[node.tsx:Node]` `[panel.tsx:Panel]` `[toolbar.tsx:Toolbar]`.
  - `ConversationContent` and `ConversationScrollButton` (`useStickToBottomContext`) require nesting inside `<Conversation>` `[conversation.tsx:ConversationScrollButton]`.
  - `CheckpointTrigger` (when `tooltip` is truthy) and `PromptInputButton` (when `tooltip` is set) render `Tooltip` without a `TooltipProvider`, requiring an ancestor `TooltipProvider`, whereas `ArtifactAction`, `MessageAction`, and `WebPreviewNavigationButton` embed their own `TooltipProvider` `[checkpoint.tsx:CheckpointTrigger]` `[prompt-input.tsx:PromptInputButton]` `[artifact.tsx:ArtifactAction]` `[message.tsx:MessageAction]` `[web-preview.tsx:WebPreviewNavigationButton]`.
  - Collapsible-backed families (`Commit`, `Plan`, `QueueSection`, `Sandbox`, `Sources`, `Task`, `TestSuite`, `Tool`) and `AgentTools`/`AgentTool` (`Accordion`) require child triggers/content to nest inside their parent root `[commit.tsx:CommitHeader]` `[plan.tsx:Plan]` `[tool.tsx:Tool]` `[agent.tsx:AgentTools]`.
- **Prompt composer submission & attachment contracts**:
  - `PromptInput` runs in dual mode (lifting text/attachments to `PromptInputProvider` if present while keeping validated `LocalAttachmentsContext` and strictly local referenced sources), validates files against `accept`, `maxFileSize`, and `maxFiles` (`onError` codes `"accept" | "max_file_size" | "max_files"`), reads `FormData` field `name="message"` in uncontrolled mode, strips attachment `id`, and converts `blob:` URLs to data URLs (falling back to original `blob:` URL on failure). In uncontrolled mode (`!usingProvider`), `form.reset()` runs immediately before `convertBlobUrlToDataUrl` and `onSubmit` (clearing DOM form inputs even if `onSubmit` fails), whereas attachments/referenced sources (`clear()`) and provider-managed `controller.textInput` clear only if sync/async `onSubmit` resolves without throwing `[prompt-input.tsx:PromptInput]`.
  - `PromptInputTextarea` submits on `Enter` whenever `!e.shiftKey` (other modifiers like `Ctrl`/`Cmd`/`Alt` are not guarded), not IME-composing, and no `button[type="submit"]` is disabled; removes the last attachment on `Backspace` when empty; and respects `e.defaultPrevented` from caller `onKeyDown` `[prompt-input.tsx:PromptInputTextarea]`.
  - `PromptInputSubmit` switches to `type="button"` and calls `onStop()` when `status` is `"submitted"` or `"streaming"` and `onStop` is provided `[prompt-input.tsx:PromptInputSubmit]`.
- **AI SDK state & streaming guards**:
  - `Confirmation` returns `null` when `approval` is falsy or `state` is `"input-streaming"` / `"input-available"`; `ConfirmationRequest` / `ConfirmationActions` render only on `"approval-requested"`, and `ConfirmationAccepted` / `ConfirmationRejected` render only on `"approval-responded" | "output-denied" | "output-available"` according to `approval.approved` `[confirmation.tsx:Confirmation]`.
  - `ToolHeaderProps` is a discriminated union requiring `toolName: string` when `type === "dynamic-tool"` and forbidding it (`never`) for typed `ToolUIPart`s; `ToolOutput` returns `null` when both `output` and `errorText` are falsy `[tool.tsx:ToolHeader]` `[tool.tsx:ToolOutput]`.
  - `Reasoning` auto-opens on `isStreaming` (unless `defaultOpen === false`) and auto-closes at most once after streaming finishes via `hasEverStreamedRef` / `hasAutoClosed` guards `[reasoning.tsx:Reasoning]`.
  - `JSXPreview` resets `error` during render on `jsx` changes, auto-closes unclosed tags via `completeJsxTag` while `isStreaming` is true, and deduplicates `onError` per `processedJsx` `[jsx-preview.tsx:JSXPreview]` `[jsx-preview.tsx:JSXPreviewContent]`.
  - `MessageResponse` memoizes strictly on `prevProps.children === nextProps.children`, ignoring non-`children` prop updates `[message.tsx:MessageResponse]`.
- **Edge-case validation, math, and event isolation**:
  - `Persona` throws `Error(\`Invalid variant: ${variant}\`)` for unknown variants (valid: `"command" | "glint" | "halo" | "mana" | "obsidian" | "opal"`) `[persona.tsx:Persona]`.
  - `InlineCitationCardTrigger` calls `new URL(sources[0]).hostname` without a try/catch when `sources[0]` is truthy, requiring a valid absolute URL `[inline-citation.tsx:InlineCitationCardTrigger]`.
  - `Context` computes `usedTokens / maxTokens` and `TestResultsProgress` divides by `summary.total` without zero-division guards `[context.tsx:Context]` `[test-results.tsx:TestResultsProgress]`.
  - `Image` discards `uint8Array` and overwrites `src` with `data:${mediaType};base64,${base64}` `[image.tsx:Image]`; `AudioPlayerElement` accepts `{ src }` or `{ data }` (base64 data URI) with `slot="media"` `[audio-player.tsx:AudioPlayerElement]`.
  - `CommitActions`, `FileTreeActions`, `StackTraceActions`, `AttachmentRemove`, and `VoiceSelectorPreview` call `e.stopPropagation()` to isolate clicks/keys from parent triggers `[commit.tsx:CommitActions]` `[file-tree.tsx:FileTreeActions]` `[stack-trace.tsx:StackTraceActions]` `[attachments.tsx:AttachmentRemove]` `[voice-selector.tsx:VoiceSelectorPreview]`.
  - `SpeechInput` detects mode once on mount (`"speech-recognition"` -> `"media-recorder"` -> `"none"`), forwards only `result.isFinal === true` transcripts in Web Speech mode, and requires `onAudioRecorded` in `MediaRecorder` mode `[speech-input.tsx:SpeechInput]`.
  - `CodeBlock` (`highlightCode`) keys its token cache by `${language}:${code.length}:${start100}:${end100}`, falls back to `"text"` for unloaded languages, and renders raw unhighlighted tokens immediately until Shiki resolves `[code-block.tsx:highlightCode]` `[code-block.tsx:CodeBlockContent]`.
  - `WebPreviewConsole` requires each `log.timestamp` to be a `Date` instance (`getTime()`, `toLocaleTimeString()`) `[web-preview.tsx:WebPreviewConsole]`.

## Side Effects
- **Module-level caches & global CSS**:
  - `code-block.tsx` mutates module-scoped `highlighterCache`, `tokensCache`, and `subscribers` Maps/Sets, asynchronously creates Shiki highlighters via `createHighlighter`, and logs failures via `console.error` `[code-block.tsx:highlightCode]` `[code-block.tsx:getHighlighter]`.
  - `shimmer.tsx` lazily populates module-scoped `motionComponentCache` via `motion.create` `[shimmer.tsx:getMotionComponent]`.
  - `canvas.tsx` imports global `@xyflow/react/dist/style.css` at module evaluation time `[canvas.tsx:Canvas]`.
- **Network requests, remote assets & embedded frames**:
  - `Persona` fetches remote `.riv` WebGL2 binaries from `https://ejiidnob33g9ap1r.public.blob.vercel-storage.com/*.riv` and autoplays them `[persona.tsx:Persona]`.
  - `ModelSelectorLogo` loads remote SVGs from `https://models.dev/logos/${provider}.svg` via unoptimized `next/image` `[model-selector.tsx:ModelSelectorLogo]`.
  - `WebPreviewBody` mounts a sandboxed `<iframe>` (`sandbox="allow-scripts allow-same-origin allow-forms allow-popups allow-presentation"`) loading `src ?? url` `[web-preview.tsx:WebPreviewBody]`.
  - `OpenIn*` items open external provider URLs (`chatgpt.com`, `claude.ai`, `t3.chat`, `scira.ai`, `v0.app`, `cursor.com`) in a new tab (`target="_blank" rel="noopener"`) with the encoded query `[open-in-chat.tsx:providers]`.
  - `convertBlobUrlToDataUrl` calls `fetch(url)` and `FileReader.readAsDataURL(blob)` during prompt submission `[prompt-input.tsx:convertBlobUrlToDataUrl]`.
- **Browser media, microphone, speech & audio APIs**:
  - `useAudioDevices` calls `navigator.mediaDevices.enumerateDevices()`, requests `navigator.mediaDevices.getUserMedia({ audio: true })` (immediately stopping tracks), subscribes to `devicechange` events, and logs errors via `console.error` `[mic-selector.tsx:useAudioDevices]`.
  - `SpeechInput` instantiates `window.SpeechRecognition`/`webkitSpeechRecognition` or `navigator.mediaDevices.getUserMedia({ audio: true })` + `MediaRecorder`, stops all `MediaStream` tracks on stop/error/unmount, and awaits `onAudioRecorded(audioBlob)` `[speech-input.tsx:SpeechInput]`.
  - `AudioPlayerElement` mounts an HTML `<audio>` element controlled by `media-chrome/react` custom elements `[audio-player.tsx:AudioPlayerElement]`.
- **Clipboard writes & timers**:
  - `CodeBlockCopyButton`, `CommitCopyButton`, `EnvironmentVariableCopyButton`, `SnippetCopyButton`, `StackTraceCopyButton`, and `TerminalCopyButton` write to `navigator.clipboard.writeText(...)` and schedule/clear `window.setTimeout` (default `2000ms`) for copied-state reset `[code-block.tsx:CodeBlockCopyButton]` `[commit.tsx:CommitCopyButton]` `[environment-variables.tsx:EnvironmentVariableCopyButton]` `[snippet.tsx:SnippetCopyButton]` `[stack-trace.tsx:StackTraceCopyButton]` `[terminal.tsx:TerminalCopyButton]`.
  - `Reasoning` measures elapsed duration via `Date.now()` and schedules/clears a `1000ms` `setTimeout` auto-close timer `[reasoning.tsx:Reasoning]`.
- **Blob URLs, file downloads & DOM/observer mutations**:
  - `PromptInputProvider` and `PromptInput` allocate and revoke `URL.createObjectURL` / `URL.revokeObjectURL` for file attachments, imperatively click/reset hidden `<input type="file">`, attach/remove `dragover`/`drop` listeners on the form or global `document` (`globalDrop`), call `form.reset()` and `form.requestSubmit()`, and read `clipboardData.items` on paste `[prompt-input.tsx:PromptInputProvider]` `[prompt-input.tsx:PromptInput]` `[prompt-input.tsx:PromptInputTextarea]`.
  - `ConversationDownload` creates a `text/markdown` `Blob` + object URL, appends/clicks/removes a temporary `<a>` on `document.body`, and calls `URL.revokeObjectURL` `[conversation.tsx:ConversationDownload]`.
  - `Persona` observes `document.documentElement` class mutations via `MutationObserver` and `window.matchMedia("(prefers-color-scheme: dark)")` changes, mutating Rive view-model RGB colors (`setRgb`) and state-machine boolean inputs `[persona.tsx:useTheme]` `[persona.tsx:PersonaWithModel]` `[persona.tsx:Persona]`.
  - `MicSelectorTrigger` attaches and disconnects a `ResizeObserver` on its trigger button `[mic-selector.tsx:MicSelectorTrigger]`.
  - `InlineCitationCarouselIndex` subscribes/unsubscribes to Embla `"select"` events `[inline-citation.tsx:InlineCitationCarouselIndex]`.
  - `TerminalContent` mutates `containerRef.current.scrollTop = containerRef.current.scrollHeight` on output updates when `autoScroll` is true; `ConversationScrollButton` calls `scrollToBottom()` `[terminal.tsx:TerminalContent]` `[conversation.tsx:ConversationScrollButton]`.
  - `SchemaDisplayPath` injects raw HTML via `dangerouslySetInnerHTML` to highlight `{param}` tokens `[schema-display.tsx:SchemaDisplayPath]`.
