# Candidate Route Namespace (`candidate`)

## Overview
Intermediate route namespace (`src/app/[locale]/(candidate)/candidate`) grouping candidate-facing assessment pages under the `/candidate/*` URL prefix.

## Subdirectories & Boundaries
- `challenges`: [`challenges`](./challenges/README.md) - Candidate active-challenges catalog, challenge brief/fork page (`[id]`), and submission/outcome workspace (`[id]/submit`).
